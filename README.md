# Enterprise AI Skills

Free, MIT-licensed Claude skills for enterprise leaders and their teams,
maintained by [Adib Kadir](https://adibkadir.com). Each skill ships with a
one-click `.skill` download in `dist/` and a companion post on the blog.

## Install

Download the `.skill` file from `dist/` and open it in the Claude desktop app
(Save skill), or copy the skill's folder into `~/.claude/skills/` for Claude
Code.
